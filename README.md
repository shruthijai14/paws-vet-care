# AI-Assisted Veterinary Care Workflow

This repository contains a modular pilot project exploring how ethically constrained AI tools can support animal welfare, Fear Free handling, and continuity of care in veterinary practice.

## Modules
- Vet Visit Stress Tracker (fully implemented)
- Post-Operative Recovery Anomaly Detection (fully implemented)
- AI Urgency Screener (prototype)
- Pain & Nutrition Guidance (prototype)

## Scope
This project does not diagnose conditions, replace veterinary judgment, or provide treatment recommendations. It is intended as a student-led exploratory pilot focused on decision support and communication.
